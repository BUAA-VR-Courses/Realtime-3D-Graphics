# 实时三维图形基础 (2024秋)

北京航空航天大学虚拟现实技术专业，大二上学期，实时三维图形基础课程作业。

共4次作业：
1. 光栅化
    - Bresenham算法
2. 渲染基础
    - Phong Shading
    - Shadow Mapping
3. 网格简化
    - Quadric Error Metrics算法
4. 光线追踪
